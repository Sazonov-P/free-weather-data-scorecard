# Free Weather Data Scorecard

Which free weather data can you trust? ERA5, ERA5-Land, ECMWF IFS and NASA POWER checked against daily observations at US weather stations, then the leaders against the free station-based grids nClimGrid and gridMET on 100 farm stations.

**Page:** https://sazonov-p.github.io/free-weather-data-scorecard/

**Germany and France edition:** https://sazonov-p.github.io/free-weather-data-scorecard/europe/ — the same sources checked against 174 DWD and Météo-France stations, each cut into the service's own day windows.

This repository holds only the published pages. Author: [Pavel Sazonov](https://www.linkedin.com/in/sazonov-pavel/). Data sources, licences and credits are listed at the end of each page.
